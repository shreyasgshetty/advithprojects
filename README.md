# Advith Projects

> A modern landing page for a construction, architecture & interior design company — built to showcase expertise, inspire trust, and convert visitors into clients.

---

## 🏗️ About

**Advith Projects** is a professional landing page designed for a full-service construction, architecture, and interior design firm. The site highlights the company's portfolio, services, and brand identity through a clean, elegant, and high-performance web experience.

---

## ✨ Features

- **Hero Section** — Striking full-screen visual with a strong call-to-action
- **Services Overview** — Construction, architecture, and interior design offerings
- **Portfolio / Projects Gallery** — Showcase of completed and ongoing work
- **About Us** — Company story, values, and team introduction
- **Testimonials** — Client reviews and trust signals
- **Contact Form** — Easy inquiry and consultation booking
- **Responsive Design** — Fully optimized for desktop, tablet, and mobile

---

## 🛠️ Tech Stack

| Layer      | Technology          |
|------------|---------------------|
| Markup     | HTML5               |
| Styling    | CSS3 / Vanilla CSS  |

## 🚀 Getting Started

No build tools required. Simply clone the repo and open the page in your browser.

```bash
# Clone the repository
git clone https://github.com/shreyasgshetty/advithprojects.git

# Navigate into the project
cd advithprojects

# Open in browser
start index.html
```
